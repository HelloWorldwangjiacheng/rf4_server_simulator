## 一、机制背景（一分钟版）

脱钩（跑鱼）由**客户端本地**判定，服务器纯被动收 14/12（f0=1/2, hooked）。客户端搏鱼态
（gfgapohfogm）进入时构造两个判定器，**ctor 时刻一次性读取输入并锁定整场**：

1. `kldglnchdec`（f0=1 松口计时器）：进场掷骰 `mkkielhmcgn(保持力)`，失败则 Random(0.5, 2.0)s
   后报脱钩（kldglnchdec.cs:96-101）。保持力在特定条件下 **×0.05**。
2. `kejihbadeej`（f0=2 钩保持 hazard）：泊松抽签 P(本帧脱钩)≈速率×dt，速率基值
   `c = 1 − clamp01(tid27.f20 × (活跃?1:0.05))`，线松弛侧 ×1.3（kejihbadeej.cs:324-327, 168）。

**×0.05 的精确分支**【实证】（hkpcgmchofj=gcnpahkoihk 挂鱼标志，FishingSet.cs:425-435；搏鱼中恒 true）：

```
挂鱼 && idmgpbkhbng()==true && !eeajjmkbjbi()  →  保持力 ×0.05   （kejihbadeej.cs:328 / kldglnchdec.cs:85）
挂鱼 && idmgpbkhbng()==false                   →  无条件全值，永不 ×0.05
```

- `idmgpbkhbng()`【推断，高置信】= 路亚类玩法分类器（实现体剥离；唯一能同时解释"路亚踩中、底钓豁免"的分支读法）
- `eeajjmkbjbi()`【实证归属】= **Fisher（玩家角色）级标志**（deghjmihlcf.cs:39），被
  `hboaciakhnc` 用来生成竿状态枚举 kieibhlheed：true→2 nnioeaijfic（手持在钓）、false→1 fhpjhepbhel
  （竿架静置）。定义体剥离。

底钓（竿架类）走全值分支 → c≈0.002/s，期望 ~470s 才可能脱钩；路亚踩 ×0.05 → c≈0.95×1.3≈1.24/s，
期望 ~0.8s 秒脱，且 f0=1 路径必走 0.5~2s 计时。

## 二、日志统计（gameserver.log）【实证】

| 竿 | 类型 | 真脱钩（f0=1/2 且 hooked=true） |
|---|---|---|
| 7b32fff7 | **路亚**（crank_s_1857, rig_type=5, rod_test 7-30g） | **43**（f0=1×25 + f0=2×18） |
| 52847463 / dbf5b643 | 底钓（potato, rig_type=12） | **0** |

**中鱼→脱钩间隔双峰指纹**：
- f0=1 簇（25 条）：gap **全部落在 [0.56, 2.0]s**——精确命中 kldglnchdec Random(0.5,2.0) 计时器，且掷骰失败 ⇔ ×0.05 分支。
- f0=2 簇（18 条）：gap 0.05~0.95s（中位 ~0.4s）——对应 kejihbadeej hazard≈1.24/s（×0.05 分支 + 不活跃 ×1.3）。

两条独立路径同时呈现 ×0.05 指纹 → **路亚中鱼时客户端判定"路亚类 && 非作钓活跃"成立**。

**用户实测纠偏**：手持路亚竿做动作（收线/抽停）时上鱼同样立刻秒脱——排除"注意力在别的竿"。
复查佐证：19:45 段五连秒脱时底钓早无搏鱼；成功链与秒脱段同为 twitch 中鱼（14/7 f5=0x410），
拟饵动作状态区分不了成败。**判定输入是客户端本地挂载态，与玩家操作无关。**

**两簇并存的意义**：19:53~19:56 专注段 6 连成功（含 bh_carp 20.7kg 搏 27s——hazard 1.24/s 下
概率≈0），证明成功鱼走了全值分支，即该判定**逐次中鱼翻转**而非整段恒 false。

次要发现（与主诉无关）：f0=2 hooked=false gap=0.02s 簇（9 条）集中在 17/9 断钩前后
（20:13:20 拟饵钩 83ecb529 断裂 hook_kg=49.43），属断件重建装备树窗口的时序问题。

## 四、归因结论

**秒脱根因链**【3.2 实证 + 4 闭环推断】：

```
模拟器搏鱼期 4/22 全部挂装组件缺运行位（拟饵/线/轮不在搏鱼挂载态）
→ 客户端脱钩机制 ctor（一次性锁定整场）读钩组实例（从挂装态钓组构造）
→ 路亚拟饵不在挂载态 → 玩法分类/作钓活跃判定翻车
→ 保持力 ×0.05 → f0=1（0.5~2s）/ f0=2（~1s）秒脱
```

- 先例支撑：PR #387 已验证"缺 1024 挂竿位时客户端钩实体不进搏鱼态"（浮漂无演出/无搏鱼指示）。
  同一运行位族（1024/2048）在搏鱼期覆盖全部组件——路亚把这套缺位放大成了脱钩判定翻车。
- 底钓豁免：竿架类走无条件全值分支，不依赖组件搏鱼挂载态 → 零脱钩。
- 与"手持做动作也秒脱"相容：判定输入是本地挂载态，与玩家操作无关。
- 服务器 14/12 判定/结算本身无错误；连珠炮体感由 `scheduleBiteState` 无脱钩冷却放大（次要）。
